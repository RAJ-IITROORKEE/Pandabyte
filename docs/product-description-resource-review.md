## Description decisions

Twenty-seven products had 31 PRODUCT INFO fragments corroborated by another field on the same listing. These fragments already appear in existing product names, summaries or specifications, so no redundant description text was added. Corroboration is source-relative and does not certify physical hardware. Three products have no captured PRODUCT INFO section. Five require individual review, and seven have previously recorded source conflicts. Two SKU-less products are held.

In particular, chip-level ADXL345 I2C/SPI support does not establish the actual breakout wiring, and the three INPUT_PULLUP claims describe software configuration rather than independently verified board wiring. Preserve these as review holds.
