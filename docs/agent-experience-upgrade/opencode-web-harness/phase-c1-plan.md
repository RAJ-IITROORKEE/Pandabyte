The broker never accepts a key from a native/browser request. The caller already owns the generation's authenticated private channel. This is not a browser-facing route.

Derive operation exactly `{kind:'tool',key:hash({runID,assistantMessageID,toolID}),requestHash:hash({name:'panda_research_search',input})}`; exclude generation from key.
